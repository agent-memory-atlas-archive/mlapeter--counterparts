- **New installs from the plugin now remember from the next session on.** An install made by the plugin's first run, or by `counterparts install` from a script, never set a size limit for the wake. With no limit, the briefing was never composed, so every session opened with "No briefing has been composed yet" even after days of use. Your memories were still saved, and recall still found them. Every Claude Code install now sets the same 9,000-byte limit the terminal install always set. An install made before this, without the setting, now uses 9,000 too, without any action from you; your configuration file is not changed. `counterparts doctor`'s Config line says which limit is in use and whether it is the default.
